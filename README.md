# Mylco Homepage Prototype

Одностраничный прототип главной страницы Mylco для показа структуры, сценариев клиента и визуальной логики.

## Что внутри

- Усиленный первый экран с понятным позиционированием и CTA.
- Сценарии клиентов: формы, творчество, литьё, новичок, B2B, производство.
- Категории материалов без выдуманных цен, SKU и остатков.
- Блок подбора материала по короткому брифу.
- B2B-блок: счёт, документы, повторные закупки, подбор замен после сверки.
- Услуги Mylco: 3D-печать, 3D-сканирование, реверс-инжиниринг, прототипирование.
- FAQ и мобильная адаптация.
- Быстрая заявка, чек-листы совместимости и блок типовых ошибок.

## Ограничения прототипа

- Живой сайт не трогается.
- Индексация закрыта через `noindex,nofollow`.
- Внешний бренд производственных услуг напрямую не упоминается; услуги позиционируются как услуги Mylco.
- Цены, SKU, остатки и конкретные условия добавлять только после сверки с фактическим каталогом и процессами.
- Preview закрыт от индексации через meta robots и `robots.txt`.

## Show notes для показа партнёру

1. Сначала демонстрировать первый экран: Mylco не просто продаёт материалы, а помогает выбрать комплект под задачу.
2. Затем пройти сценарии клиента и каталог: все блоки без неподтверждённых цен, SKU и остатков.
3. Отдельно показать B2B и услуги Mylco по 3D-печати, 3D-сканированию, реверс-инжинирингу и прототипированию.
